# CryptoReport

Учебный проект по анализу цен криптовалют с использованием публичного API CoinGecko.

## Возможности

- Регистрация и авторизация пользователей (через email и пароль)
- Получение исторических данных по популярным криптовалютам (Bitcoin, Ethereum, Solana, Cardano и др.)
- Интерактивный график изменения цены
- Таблица с данными
- Сохранение отчёта в CSV
- Веб-версия + Desktop-версия
- Запуск через Docker

## Структура проекта

- `web-version/` — веб-приложение на Flask
- `desktop-version/` — десктопное приложение на Tkinter
- `Dockerfile` и `docker-compose.yml` — для запуска веб-версии в контейнере
