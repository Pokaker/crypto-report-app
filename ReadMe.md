\# CryptoReport



Веб-приложение для анализа цен криптовалют с использованием публичного API CoinGecko.



\## Функционал



\- Регистрация и авторизация пользователей

\- Получение исторических данных по криптовалютам (Bitcoin, Ethereum, Solana и др.)

\- Интерактивный график цены

\- Таблица с данными

\- Сохранение отчёта в CSV

\- Запуск через Docker



\## Технологии



\- Python + Flask

\- Chart.js (графики)

\- Docker + Docker Compose

\- CoinGecko API



\## Запуск через Docker (рекомендуется)



```bash

docker compose build

docker compose up
